# Python Utility Scripts

A collection of basic Python scripts for simple mathematical calculations and printing text.

## Files

* **`square.py`**: Calculates the square of a given number.
* **`addition.py`**: Adds two numbers together.
* **`name.py`**: Prints a name.

## Usage

Run any of the scripts using Python 3:

```bash
python square.py
python addition.py
python name.py

```
